Ableton Live: Settings > Plug-Ins, make sure "Use VST3 Plug-in System Folders" or "Use Audio Units" is on, then click Rescan. Hypernova shows up under Plug-Ins > Arrow.

Start with Classic Log, Rager 808 and Hypernova.

Share sounds: preset menu > Export current sound. Friends drag the .hnpreset file onto Hypernova to import it.
